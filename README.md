# Randomizer

A native mod for the [Super Mario Sunshine PC port](https://github.com/chasem-dev/sms-pc-port), built with the [mod SDK](https://github.com/chasem-dev/sms-mod-sdk).

22 unlocks (the double, triple and side jumps, the spin jump, wall kicks, ground pound, grab, ground spin, rollout, climbing, the Y camera, the blooper, the rollercoaster cart, Yoshi, the four nozzles with the spam spray, and the shirt, sunglasses and helmet) start locked. Each is given by one Shine; collecting it shows `UNLOCKED <name>`. The levels can be shuffled too: each level's entrance loads another one.

The seed decides both, worked out as the original randomizer (TheAzack9's Kuribo module) does, draw for draw: a seed gives the same game. The generator walks the game from Delfino Plaza, so every seed can be finished. One more place than the original: the plaza's Shine behind the wooden door broken with the turbo nozzle (by Yoshi's egg, at the foot of a bell tower) may hold an unlock, needing the turbo. The goop Piranha Plants on the plaza's ways to Bianco Hills, Ricco Harbor and Gelato Beach are in the original's logic: those ways need the spray nozzle (the hover trick is not counted on).

## What it needs

- The port, with the mods it loads from `mods/`. Copy the `randomizer` folder (what `cmake --build` writes to `SMS_MODS_OUT`) into the game's `mods/`.

## In the game

- A new game: at file select, the randomizer's screen opens over an empty file's menu ("New"; API 1.6): the seed (type its digits on the keyboard, Backspace erases one, or use left and right), a new seed, the entrances (off, or which it shuffles), start with all unlocks, the win condition, the 100-coin Shines, the blue coin trades and unlocks, Shines <> coins, infinite lives, open plaza gates, the spoiler log. A starts the game as set, B goes back. (With API 1.5 it opens once the file is started, and both start it.)
- The Mods menu (F1): Randomizer on or off, the seed (New seed draws one and shows it in its place), the win condition (the Shines that open Corona Mountain), entrances (Off keeps every level in its place), start with all unlocks, use random seed, infinite lives (not in the original: the lives never go down and there is no game over). 100-coin Shines hold unlocks (not in the original): each world's 100-coin Shine (100 to 107, the plaza's too) is one more place an unlock may go, in the episodes whose scene places 100 coins or more (the plaza, Ricco Harbor 2-8, Gelato Beach 2 and 7, Noki Bay 1, 2, 4-8; the coins enemies and boxes give are not counted), needing the way in's needs and the spray nozzle. With Entrances Off every level stays in its place, and the unlocks are placed for the game's own map, so the seed can still be finished; Mario has the spray nozzle from the start then (nothing in Delfino Plaza can be had without it), and the 21 other unlocks come from Shines. This is not in the original randomizer.
- The logic (always; seeds differ from the original's): the original's (the shuffle, the ways in and what they need) and, on top, what the normal logic of the [SMS apworld](https://github.com/Joshark/archipelago-sms) asks of each Shine (its nozzles and Yoshi, Shines had, another Shine or blue coin reachable), except that a blue coin, or a Shine whose task is spraying, the apworld lets the hover nozzle's water get as well as the spray's asks the spray, and where the [mariopartylegacy.com](https://mariopartylegacy.com/guides/super-mario-sunshine-blue-coins-and-walkthrough) guide says otherwise (a few coins' nozzles; Pinna Park's crates, broken only in episode 2; the grab, ground pound or climbing some coins ask, which the apworld does not lock). The apworld has no entrance shuffle, so the Shines found only in the secret courses keep the original's needs alone, and a new file starts in a level drawn as the original draws it (one with nothing to have from the start by the apworld is drawn again). `src/ap.inc` is generated from the apworld's region files and the game's scenes.
- Blue coin unlocks (off by default; not in the original): an unlock may go on a blue coin, with the apworld's needs for it, in the levels whose scenes have it: all 240 (placed, or behind a hidden object with its number; those an animal, enemy or NPC gives, in the scenes where that kind is). The unlock comes as the coin is picked up.
- Shines <> blue coins (off by default; not in the original; API 1.6 beta 2): 5 to 30 pairs, a seed's own draw, of a Shine and a blue coin trade places. The Shine is taken quietly (`SMS_EV_SHINE_TOUCH`, no Shine Get, Mario plays on) and gives a blue coin; the blue coin gives the Shine (its flag and the Shine count). The logic has each where the other is. Never a Shine of the plaza, of a secret course, a trade or the turbo door's, nor a coin only Corona Mountain opens. The spoiler lists the pairs.
- Entrances (Mods menu and the setup screen; kept with the file; not in the original): whether the levels are shuffled, which entrances it moves, and among which. *Off* (the default) keeps every level in its place. The choices run in this order: Off, Worlds, Secret courses, Worlds and secret courses, Secret courses and the rest mixed, All mixed. *All mixed* is the original's: every level may be behind any entrance. *Worlds among themselves*: only the worlds' entrances (the levels in areas 2-9, 0xD and 0xE) swap with each other; everything else stays. *Secret courses among themselves*: only the secret courses (areas 0x15 to 0x33) swap with each other. *Worlds and secret courses, each among its own*: both, in two separate pools. *Secret courses among themselves, the rest mixed*: the secret courses in one pool, every other level in another. A level that is not shuffled keeps its own entrance. The generator walks the same way in every mode, so every seed can still be finished; the mode is part of the seed's game (a different mode gives a different game).
- The screen has four tabs (L and R change tab): PLAY (the seed, a new seed, the spoiler log, Start), OPTIONS (entrances, all unlocks, the win condition, the places that hold unlocks, infinite lives, open plaza gates) EXCLUDED LOCATIONS and PLANDO (below). EXCLUDED LOCATIONS: (left and right choose the list: entrances by zone, Shines, blue coins or entrances by episode; typing letters, digits or space filters it by name, Backspace erases; A puts a row in or takes it out; what is excluded is on the right). An entrance excluded keeps its level; a Shine or blue coin excluded holds no unlock. The list is kept in a file:
- Exclusions file (`exclusions.txt` in the mod's data folder, one line each, `#` for a comment; read when the mod loads and when the new game screen opens; not in the original): `entrance 02` keeps the entrance to every level of area 02 on its own level (four digits, `entrance 0201`, for a single one), `shine 12` puts no unlock on Shine 12, `coin Tourist` (or `coin Bianco Hills/Tourist`) puts none on that blue coin. The generator then leaves those out; with many excluded places a seed may have no game (the setup screen and the game say so in red, and the mod does nothing for that seed).
- Plando (the PLANDO tab, or `plando.txt` in the mod's data folder, one line each; read with the exclusions; not in the original): you place what you want and the generator draws the rest.
  - `unlock double jump = shine 12` (a Shine by its number or its name) or `unlock hover nozzle = coin Tourist` (a blue coin, with the Blue coin unlocks option on) gives that unlock there, once the place is reachable; the same unlock is not drawn anywhere else. With *Start with all unlocks* on, the unlocks the plando places are the only ones not had from the start (the others are all had): the plando then sets what the game still locks.
  - `entrance 0200 = 0501` (levels as area and episode in hex) makes the entrance to level 0200 load level 0501, and `entrance start = 0405` is where a new file starts. They work in every Entrances mode, Off included (then they are the only entrances that move): the plando is placed first, and the shuffle only moves what the plando did not place. The level a plando entrance leaves behind goes to the entrance whose level it took.
  - In the tab, A on a row chooses what it gets (type to filter, A puts it there), A on a row already set takes it out.
  - If what is placed cannot be reached (a nozzle on a Shine that needs that nozzle, two entrances to one level...), the seed has no game: the setup screen and the game say so in red.
- Blue coins that look like a Shine (options *Blue coins that give a Shine look like one* and *Blue coins that hold an unlock look like a purple Shine*, on by default; API 1.8 beta 3): with the Shines <> blue coins and blue coin unlocks options, a blue coin that gives a Shine is drawn with the game's own Shine model and its sparkles, and one that holds an unlock the same in purple. On an older game the first is a gold coin (or `coinshine.bmd`, when the mod has it) and the second a purple coin. *Shines that give a blue coin are blue* tints the Shines that hold a coin.
- The D-pad puts an unlocked nozzle on FLUDD: up the hover, left the rocket, right the turbo (also with every unlock from the start).
- The pause menu (and F4) shows the seed, the rules and the unlocks you have.
- The tracker (hold X, then press Y, on the pause menu): a map of each place (the [Sunshine_Pop](https://github.com/LiterallyNoOne1/Sunshine_Pop) PopTracker pack's markers and maps, by [VGCartography](https://www.deviantart.com/vgcartography)), a square for every Shine and blue coin, green when the logic reaches it with the unlocks, Shines and Shadow Marios you have, red when not, grey once had. It shows every place, so it does not tell where the unlocks are. With the shuffle, a place is green only once the file has been in a level it is in (`levels.txt` with the save file; the plaza's places always), as the logic knows the whole shuffle but you do not. L and R turn the maps, the stick moves a cursor that names the places of a square (with its number: `Shine 88`, `Blue coin 5`, the numbers of `exclusions.txt`), B or Y closes it, A hides the places you have and X those out of logic. The 13 maps the mod names in `src/tracker.inc` are in `mod/tracker/images/maps` (copied to the mod's `tracker/images/maps` by the build), with the pack's LICENSE.
- Write spoiler log (Mods menu) writes `spoiler-SEED.txt` in the mod's data folder: which Shine gives each unlock (where it is, and the entrance that leads there) and the level each entrance loads, with the game's own names; then every Shine by number and name (`SHINE NAMES`).

## What the mod API gives it

Mario's actions (`SMS_EV_PLAYER_STATUS`), the shuffle (`SMS_EV_STAGE_LEAVING`), the Y camera (`SMS_EV_PAD_READ`), the message and the list (`SMS_EV_SHINE_COLLECTED`, `SMS_EV_DRAW`), the options and the seed (`config`). The nozzles and the outfit use API 1.5 (`SMS_EV_PLAYER_NOZZLE`, `player->set_nozzle`, `set_fludd`, `set_outfit`); on a game without it they are left alone. The spam spray (A in bursts while R is held) uses `SMS_EV_NOZZLE_FIRE` (API 1.5).

## Build

```sh
cmake -S . -B build -DSMS_MODS_OUT=/path/to/the/game/mods
cmake --build build
```

`-DFETCHCONTENT_SOURCE_DIR_SMS_MOD_SDK=<path>` builds against a checkout of the SDK.
